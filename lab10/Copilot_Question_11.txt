Copilot: Hello Data Science Student! Exactly: a score of 65 is "low" because the condition score > 65 is false. score is the target if it’s the outcome you want the model to predict or categorize. Features are the input information used to make that prediction. In apply(lambda x: ...), x is the value or row passed to the function—not automatically an index. So model_data["score"][x] wrongly tries to use x as an index into the score column. If applying to the score column, use x directly; if applying row by row, access the row’s score with x["score"].
